# TwoDrive Office AutoSave v0.1.0 · 开发预览版

为 ONLYOFFICE Desktop Editors 和 LibreOffice 提供文档自动保存开关。

- TwoDrive 挂载目录内的文档保存到原位置；目录外及未命名文档保存当前编辑内容的副本。
- 默认副本目录为 `~/TwoDrive/OneDrive/Office AutoSave`，用户可以选择 TwoDrive 内的其他目录。
- 支持文档、电子表格及演示文稿；提供关闭开关、立即保存、状态提示、失败重试和目标冲突检测。
- 安装程序不会启动编辑器；开关默认关闭。

## 下载与安装

**安装提示（2026-10-14）：** v0.1.0 源码附件的安装脚本存在 systemd 工作目录引用错误，已在仓库 `main` 分支修复并完成本机安装验证。首次配置桥接服务请使用 `main` 分支的最新安装脚本；两个插件安装包不受此问题影响。

最新 `main` 安装脚本同时改为按需桥接：登录时不启动 Python 进程，ONLYOFFICE 插件首次连接时唤醒；编辑器关闭且没有请求或保存任务后自动退出。LibreOffice 不使用外部桥接服务。

- `twodrive-autosave-0.1.0.oxt`：LibreOffice 扩展。
- `twodrive-autosave-0.1.0.plugin`：ONLYOFFICE 插件。
- `twodrive-office-0.1.0.tar.gz`：完整项目源码、安装脚本和本地桥接服务。
- `SHA256SUMS`：以上附件的 SHA-256 校验值。

ONLYOFFICE 还需要本地桥接服务，不能仅安装 `.plugin` 文件。获取仓库当前 `main` 分支源码后，按 [安装说明](https://github.com/LumiaBlack51/twodrive-office#安装) 配置即可。

## 已验证与限制

LibreOffice 26.2.5.2 和 ONLYOFFICE Flatpak 9.4.0（内核 9.4.0.129）已完成实际应用保存测试。21 项 Python 测试、5 项 Node 调度测试通过；包括真实当前修改、指定目录副本、原文件保留、带图片 DOCX、关闭开关及冲突处理。

ONLYOFFICE 面板需保持打开，其原生接口适配器只在上述版本核实。当前拒绝加密文档、含宏文件和旧版二进制 Office 格式。复杂嵌入对象、音视频、大型样本集合及 ONLYOFFICE ODF 转换尚未完成实际应用验证。

“已本地保存”不代表 OneDrive 上传完成，上传由 TwoDrive 负责。本次未执行真实 OneDrive 端到端上传测试。完整记录见 [验证记录](https://github.com/LumiaBlack51/twodrive-office/blob/v0.1.0/docs/verification.md)。

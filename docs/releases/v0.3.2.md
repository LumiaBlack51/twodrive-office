# TwoDrive Office 0.3.2 preview

PowerPoint recovery snapshots now ignore serialization-only revision numbers, editing time and modification time. Changes to slides, media and other package parts still produce durable revisions. After two matching snapshots the add-in waits for input, periodically checks for silent automation edits and honors its publication deadline. Native save confirmation uses a single-use token and the SHA-256 digest of the saved package. The Wine worker reads saved files in 256 KiB blocks. Failed automatic operations back off up to 60 seconds. Reentrant close processing waits for the existing Office timer.

Install the bridge and Wine add-in together using the included installer. The Linux TwoDrive 0.2.30 package separately coalesces short-lived Office uploads. The default publication interval is 180 seconds. See the Wine guide and verification record for installation and tested scope.

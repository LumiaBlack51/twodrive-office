# TwoDrive Office AutoSave 0.3.1 (Preview)

Adds Microsoft 365 x64 on Wine/Soda: a native COM adapter for Word, Excel and
PowerPoint, with persistence, mount validation and recovery in the existing
Linux bridge. The Wine ZIP includes the DLL, Linux runtime and an offline,
explicit-prefix installer. No .NET/VSTO or TwoDrive backend changes are required.

Dirty content is captured as a complete private local revision, normally within
five seconds. Original-file publication uses Office's own Save every 180 seconds,
on Save now or on an enabled document close. Native dirty flags remain until that
native Save succeeds. Close saving runs on a posted Office STA callback because
Excel refuses reliable saves/exports inside BeforeClose. Failure keeps the document
open and preserves pending local content. Ctrl+S, persistent per-document pause,
copy mode and all-editor-exit recovery are supported.

Validation and exact limits are in [verification](../verification.md) and
[Wine installation/compatibility](../wine.md). The native loader, callback methods,
real timer, current OOXML content and cleanup are tested with generated documents
on a copied prefix and authenticated private Xvfb. This is not a claim of real
OneDrive end-to-end upload, x86/other Office or Wine compatibility, complex-file
coverage, protected-document workflows or actual mouse-click ribbon verification.

Also improves ONLYOFFICE close delivery: an authenticated simple beacon avoids
a new cross-origin DELETE preflight while its renderer unloads. The original
keepalive path remains a fallback. Existing pending-data and origin/host/token
protections continue to apply. 54 Python and 22 Node tests pass; the actual
ONLYOFFICE PNG DOCX close/publication regression and headless LibreOffice
Writer/Calc/Impress also pass.

# TwoDrive Office AutoSave 0.2.1 (Preview)

Repeated exports of an unchanged native model no longer convert and replace the
document just because their HTTP revision increased. The bridge compares the
model, media and source independently of request ordering, and still validates
the mount, target and external-change fingerprint before acknowledging a no-op.
Edits, media changes, failed requests and lost replies retain their protections.

The installer now covers both native user-plugin directory layouts used by
Desktop 9.4 and 10.0, including the Flatpak. Update the bridge along with the
plugin. It does not launch an editor or edit an open document.

The regression fails before the fix and passes after it. Python/Node checks,
package construction and actual isolated Desktop verification are recorded in
[the verification log](../verification.md). This is a preview, not a claim of
real OneDrive end-to-end sync or complete SDK/document-format compatibility.

# TwoDrive Office AutoSave 0.3.0 (Preview)

Frequent edits now save durable full documents outside the TwoDrive mount. Only
its latest local revision is published every 180 seconds, on document close,
or with Save Now. Failed publication keeps the private local revision for retry;
external modifications stop overwrite. The editor saved marker confirms durable
local saving, while the mount file can lag by one interval. Native Ctrl+S keeps
its own editor behavior and may upload earlier.

Configure the interval with `configure --sync-interval 180`. Use `pending` to
inspect retained revisions. After a crash, close all office applications before
running `recover`; the ONLYOFFICE on-demand bridge can also recover once every
office process has exited. Never clean the pending directory as disposable cache.

Pair with TwoDrive 0.2.22 or later to stop untouched writable open/close handles
from uploading. Uploads still use complete files; this does not implement a
Microsoft differential-sync protocol.

Validation: 40 Python and 21 Node tests; isolated ONLYOFFICE Desktop 10 PPTX,
PNG DOCX and XLSX; headless LibreOffice Writer, Calc and Impress. Includes local
staging before mount publication, interval/close/restart/conflict protection,
save markers, delayed/lost replies, undo/redo, idle stability and native Ctrl+S.
See [verification](../verification.md) for exact limits. Real OneDrive round trips,
all document types and older native SDKs were not tested in this release.

# TwoDrive Office AutoSave v0.2.0 · 开发预览版

打开 TwoDrive 挂载目录内的文档即自动开启原位保存，同时修复 ONLYOFFICE 已写入文件却仍显示星号、关闭时继续提示保存的问题。

- ONLYOFFICE 改为静默后台启动，无需手动打开插件；上方 **TwoDrive → 自动保存** 提供状态与开关，关闭面板后继续保存。
- LibreOffice 打开目录内文档时自动开启；手动暂停后，本次打开期间不会自动重开。
- 未修改的文档不会仅因打开而重新导出或覆盖。目录外和未命名文档保持关闭，可手动选择 TwoDrive 内的副本目录。
- ONLYOFFICE 原位写入成功后，仅在当前内容仍与已提交快照一致时清除星号。保存期间的新修改、失败、丢失响应都保留待保存状态并重试；保存副本时保留原文档的关闭保护。
- 包含 v0.1.0 发布之后的安装脚本与按需桥接修复：通过 systemd socket 首次连接时启动 Python，编辑器关闭、请求完成后退出。

## 下载与升级

- `twodrive-autosave-0.2.0.oxt`：LibreOffice 扩展。
- `twodrive-autosave-0.2.0.plugin`：ONLYOFFICE 插件。
- `twodrive-office-0.2.0.tar.gz`：完整源码、安装脚本和本地桥接服务。
- `SHA256SUMS`：三个附件的 SHA-256 校验值。

解压源码附件，在源码目录按 [安装说明](https://github.com/LumiaBlack51/twodrive-office/tree/v0.2.0#安装) 运行配置和安装脚本。ONLYOFFICE 仍需要本地桥接，不能只安装 `.plugin`。现有连接设置可继续使用。

安装不会启动或重启办公软件、打开文档。请在方便时自行重新启动办公软件，让新的后台启动配置生效。

## 验证与限制

25 项 Python、18 项 Node 测试通过，并完成隔离的实际应用验证：ONLYOFFICE Flatpak 9.4.0 的 PPTX、带 PNG 的 DOCX、XLSX 自动开启、原位保存、保存点与关闭；目录外和未命名 PPTX 保持手动副本模式；真实控制面板开关及关闭面板后继续保存；延迟响应期间的新编辑与丢失响应重试。LibreOffice 26.2.5.2 使用独立 profile、`--headless` 验证自动开启和原位保存，以及 Writer、Calc、Impress 的副本导出。

ONLYOFFICE 的 Desktop 原生适配器只在上述版本核实。无法识别的 SDK 保存点结构会保留未保存提示。加密文档、含宏文档和旧二进制 Office 格式暂不支持；复杂嵌入对象、音视频、大型样本和 ONLYOFFICE ODF 转换仍需验证。

所有文件测试使用临时目录模拟挂载，没有操作真实 TwoDrive 挂载或用户工作文件。插件确认本地写入，真实 OneDrive 端到端上传未验证。完整记录见 [验证记录](https://github.com/LumiaBlack51/twodrive-office/blob/v0.2.0/docs/verification.md)。
